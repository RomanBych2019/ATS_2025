# ATS

Проект тарировочной станции на основе контроллера ESP32.
Дисплей на базе Nextion 5'.

# Основные возможности

Работа с ДУТами с интерфейсами:
- Аналоговый, напряжение
- Аналоговый, частота
- RS485, протокол LLS
- BLE фирмы Эскорт

Работа в режимах:
- Счетчик - подсчет топлива, прошедшего через счетчик. Запоминание промежуточных значений, управление насосом.
- Выдача топлива - выдача введенного объема топлива.
- Автоматическое выкачивание - выкачивание топлива из бака до тех пор, пока скорость потока не станет менее 5 л/мин.
- Калибровка счетчика - вычисление количества импульсов для калибровки счетчика.
- Тарировка бака - тарировка бака порциями топлива.

Станция передает данные в терминал спутникового мониторинга, подключенный по RS485 (19200, 8, 1), протокол передачи Modbus RTU.
Станция записывает лог работы во внутреннюю flash-память.

# Сборка

Проект собирается через PlatformIO. В `platformio.ini` есть два варианта прошивки:

- `esp32dev` - основная сборка без Web Portal и Wi-Fi.
- `esp32dev_web` - сборка с Web Portal, Wi-Fi и OTA через флаг `ENABLE_WEB_PORTAL`.

Команды сборки:

```sh
pio run -e esp32dev
pio run -e esp32dev_web
```

В обычной сборке `WebUi.cpp`, `WifiManager.cpp` и зависимость `GyverPortal` не используются. В web-сборке они подключаются на этапе выбора environment.

# Web Portal

Web Portal доступен только в сборке `esp32dev_web`.

Станция работает в режиме точки доступа:
- SSID: `WiFi ATS`
- Пароль: `00000001`

Страницы:
- `192.168.4.1` - управление станцией и доступ к логу.
- `192.168.4.1/ota_update` - загрузка новой прошивки.

# Структура

Крупные части логики вынесены из `main.cpp` в отдельные модули:
- `HmiRenderer` - рендеринг экранов Nextion.
- `WebUi` - страницы и обработчики Web Portal.
- `WifiManager` - настройка Wi-Fi и login portal.
- `ModbusTable` - таблица Modbus и обновление регистров.
